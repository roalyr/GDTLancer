# Preset catalog

Generated by `tools/classify_presets.gd` from the presets in this folder: every exported design, by family and weight class, for picking archetypes when building factions. Hull, fit and pilot behaviour stay together in each preset; the columns only describe it.

- **Temperament**: how readily its pilot starts, keeps up and chases fights against how soon it runs.
- **Traits**: genes that went most of the way from where evolution started to an end of their range.
- **Equipment / modules**: the fit it evolved with (the store sells the hull bare and these parts apart). **Hull WP**: the bare hull's price.
- **Proven**: flew 10 lives or more. **Lives / fitness**: when exported (blank: exported before these were kept). Fitness is return on cost, less 1 for a lost ship; combat roles add the enemy value they destroyed.
- The ship file is `preset_ship_<id>.tres`, the pilot `agent_preset_<id>.tres`, in the folder named.

# GDTLancer

[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)

**GDTLancer** is a hybrid space game combining real-time 3D flight with automated digital board game mechanics.

## The Setting

Set in a raw, early-stage frontier, there are no sprawling empires, galactic corporations, or massive navies. Human society is fragmented into small, isolated station communities where spaceflight is rare, perilous, and logistically heavy. The game focuses on community survival, resource scarcity, and personal dependencies rather than heroic space opera.

## Core Gameplay

The game alternates between two primary modes:
- **Mode A (3D Flight):** Real-time 3D piloting and spatial navigation between sectors.
- **Mode B (2D Board):** Contextual 2D tabletop board interfaces for social encounters, station interactions, vessel management, and stellar survey.

## Design Philosophy

- **Automated Playing Board:** The engine manages world state, tags, tokens, and board layout.
- **Player-Led Narrative:** The system presents visual cues and state mutations, leaving narrative fiction to the player's imagination.

## Technology Stack

* **Primary Engine:** Godot Engine 3 (3.6 stable, GLES2)
* **Auxiliary Tooling:** Python 3
